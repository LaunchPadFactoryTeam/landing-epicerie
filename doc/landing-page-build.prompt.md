# Prompt d'execution — Landing page LaunchPad x Epiceries fines

Tu dois concevoir et implementer la landing page complete du projet a partir du brief source suivant :

- `./brief-landing-page-epiceries-fines.md`

## Source de verite

Le fichier `brief-landing-page-epiceries-fines.md` est la reference principale.
Tu dois le lire integralement avant de commencer.

En cas d'ambiguite :

1. Le brief fait foi.
2. S'il reste une incoherence mineure, choisis l'option la plus coherente avec l'objectif commercial de la page.
3. Ne pose une question que si un blocage empeche concretement d'implementer la page.

## Objectif

Produire une landing page de vente complete, responsive, elegante et convaincante pour LaunchPad, ciblee sur les epiceries fines independantes en France.

Le site doit inspirer :

- confiance
- qualite
- expertise
- clarte
- maturite

## Livrables attendus

Tu dois creer ou mettre a jour uniquement ces 3 fichiers :

- `index.html`
- `style.css`
- `script.js`

## Contraintes de production

- HTML5 semantique
- CSS natif uniquement, sans framework
- JavaScript vanilla uniquement pour les interactions legeres
- aucune dependance externe sauf Google Fonts si necessaire
- page responsive mobile-first
- SEO conforme au brief
- accessibilite correcte
- placeholders `#` conserves quand le brief le demande

## Attendus de design

- Respecter strictement la section `Identite visuelle` du brief
- Ne pas produire un design de SaaS generique
- Faire une page premium, sobre, lisible, chaleureuse et credible
- Utiliser de vrais rythmes visuels : hero fort, sections aeriennes, cartes propres, preuves visibles
- Soigner particulierement la section sur l'application DLC, avec layout texte a gauche / illustration a droite et elements flottants autour du visuel

## Attendus de contenu

- Respecter la structure de sections demandee dans le brief
- Reprendre les textes du brief comme base prioritaire
- Corriger seulement les coquilles evidentes si necessaire
- Ne pas inventer de promesses chiffrrees non presentes dans le brief
- Garder le ton clair, concret, professionnel, sans jargon inutile

## Methode de travail demandee

1. Lire entierement le brief
2. Construire la structure HTML complete
3. Implementer le systeme visuel et responsive en CSS
4. Ajouter les interactions JS minimales demandees
5. Verifier la coherence avec la checklist finale du brief
6. Corriger les ecarts avant de terminer

## Verification finale obligatoire

Avant de considerer le travail termine, verifier explicitement :

- presence d'un seul H1
- presence des H2 dans le bon ordre
- meta title et meta description
- balise lang en francais
- CTA principaux avec lien `#`
- formulaire lead magnet fonctionnel avec message de succes JS
- responsive mobile / tablet / desktop
- menu mobile fonctionnel si present
- images avec alt en francais
- section application DLC bien mise en valeur
- footer complet

## Resultat attendu

Le rendu final doit sembler credible pour une vraie mise en ligne, pas comme une maquette brouillon ou une simple demo technique.
